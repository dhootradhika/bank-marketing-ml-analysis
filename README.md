# 📊 Bank Marketing Dataset Analysis

This project analyzes the Bank Marketing Dataset from the UCI Machine Learning Repository to predict whether a customer will subscribe to a term deposit.

## 🔍 Key Highlights
- Real-world banking dataset (45,211 records)
- Data cleaning, EDA, and preprocessing
- Class imbalance analysis
- Machine Learning model comparison

## 🤖 Models Used
- Decision Tree Classifier
- Random Forest Classifier
- Linear Support Vector Machine (SVM)

## 📈 Results
- Random Forest performed best overall
- Class imbalance affected minority class predictions
- Precision, Recall, and F1-score used for evaluation

## 🛠 Tech Stack
- Python
- Pandas, NumPy
- Scikit-Learn
- Matplotlib, Seaborn

## 📂 Dataset
https://archive.ics.uci.edu/dataset/222/bank+marketing
